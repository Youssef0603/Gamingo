# Gaming words data folder

Drop this `src/data` folder into your app.

- `phrases.ts` keeps the same `phrases` export and `tx/t` structure used by your app.
- Contains 413 gaming phrases/words ordered from most common to more situational.
- Every phrase includes: `en`, `fr`, `es`, `de`, `ar`, `it`, `pt`, `hi`, `nl`, `pl`, `tr`, `ru`, `ja`, `ko`, `zh`.
- Existing hand-written translations from your original data were preserved when the English phrase matched.

Note: for the newly generated large pack, translations are starter app-data translations and should be reviewed by native speakers before publishing as professional localization.
